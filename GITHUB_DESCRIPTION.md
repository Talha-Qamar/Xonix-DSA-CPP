## 📄 Full Description
**Optional: Use this for "About" section or repository discussions:**

### Xonix Game - Data Structures & Algorithms Implementation

A recreational implementation of the classic Xonix arcade game developed as an academic project to demonstrate proficient use of data structures and algorithms in C++. Features custom implementations of Hash Tables, Linked Lists, and Min Heaps integrated into real-world game mechanics.

**Key Features:**
- Single & Multiplayer gameplay with AI pathfinding
- Custom DSA implementations for game logic optimization
- Player authentication & leaderboard system
- Real-time graphics using SFML
- Advanced collision detection and tile-based rendering

**Technologies:** C++, SFML Graphics Library, Visual Studio 2022

**Skills Demonstrated:** 
- Object-Oriented Programming (OOP)
- Data Structure Implementation & Optimization
- Algorithm Efficiency Analysis
- Game Loop Architecture
- File I/O & Persistent Data Management
- UI/UX Implementation
